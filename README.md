# Housing-Style Target Prediction (SkillCraft ML Task 01)

## Overview

This project demonstrates **linear regression** using a generated, synthetic dataset with three input features:

- `rm`: average number of rooms
- `lstat`: a synthetic lower-status population percentage feature
- `tax`: a synthetic property-tax feature

The target is generated by a simple formula plus random noise. The project is intended to demonstrate a basic machine-learning workflow, not to estimate real estate prices.

## What it does

1. Generates 500 reproducible synthetic records using NumPy.
2. splits the records into training and test sets.
3. Trains a scikit-learn `LinearRegression` model on the training set.
4. Reports MAE, RMSE, and R-squared on the held-out test set.
5. Accepts three feature values and returns the model's **synthetic target-unit output**.
6. Plots actual versus predicted targets for the held-out test records.

## Important limitations

- No real housing dataset is used.
- The target is artificial and has no real currency unit. Outputs must not be interpreted as dollars or thousands of dollars.
- Because the target was constructed from a known linear formula, this is mainly a learning demonstration; it does not prove that the same relationships hold in real housing markets.
- Inputs should be within the approximate ranges represented by the generated data. The script does not validate whether a value is realistic for a real location.
- This is not a production-ready valuation tool.

## Requirements

- Python 3.10 or later
- NumPy
- pandas
- scikit-learn
- Matplotlib

Install the dependencies:

```bash
python -m pip install numpy pandas scikit-learn matplotlib
```

## Run

From the repository directory:

```bash
python SCT_01.py
```

The program prints test-set metrics, asks for feature values, then opens a scatter plot. Close the plot window to finish the program.

## Concepts demonstrated

- Synthetic data generation
- Feature matrix (`X`) and target vector (`y`)
- Train/test split
- Fitting a linear regression model
- Regression evaluation metrics: MAE, RMSE, and R-squared
- Prediction from user-provided inputs
- Visual inspection of test-set predictions
